Progressive Web App is one of the most surprising piece of technology that I heard about since I'm developer. It allows you so many things without degrading the Developer Experience (DX).

A progressive web app (PWA) is an app that's built using web platform technologies, but that provides a user experience like that of a platform-specific app.
MDN

I started working on it recently. One of the first missions I got from my new job was to refactor a mobile app used with an internal purpose.

DX is key

Starting to code for mobile can be a bit overwhelming, especially when you come from Web Development. Builds, Cross Platforms compatibility, Stores requirements, etc. So many things that you don't care about for development. Yes, React and React Native are very similar, but the layer added by the mobile environment is... quiet interesting.
